# Política de idiomas de ARDREC

## Español

La documentación se presenta primero en español y después en inglés.
Ambas versiones deben conservar el mismo contenido técnico.

Los mensajes de commit utilizan un asunto en español y un cuerpo con
secciones Español y English. Las descripciones de cambios, incidencias,
decisiones y pruebas siguen el mismo criterio.

Los identificadores de código, rutas, campos JSON y códigos de estado
conservan nombres técnicos estables. Sus explicaciones son bilingües.
En la matriz de algoritmos, name conserva el título español y name_en
contiene su traducción inglesa.

Las traducciones no cambian el modelo matemático, las reglas operacionales
ni el estado de implementación o verificación.

## English

Documentation is presented first in Spanish and then in English.
Both versions must preserve the same technical content.

Commit messages use a Spanish subject and a body containing Español and
English sections. Change descriptions, issues, decisions and test reports
follow the same convention.

Code identifiers, paths, JSON fields and status codes retain stable technical
names. Their explanations are bilingual.
In the algorithm mapping, name retains the Spanish title and name_en
contains its English translation.

Translations do not change the mathematical model, operational rules,
implementation status or verification status.
