# Registros de desarrollo

## Español

F1-bootstrap.json conserva el resultado observado al crear la estructura
local y el entorno Python. Sus campos y códigos son datos estructurados.

Los valores PENDING, NOT_TESTED y NOT_RUN describen el estado registrado
en ese momento. No constituyen una consulta del estado actual.

docs/pendientes.md conserva la lista inicial de tareas de la línea base.
Su ejecución se acreditará mediante actas posteriores vinculadas a commits.
La lista inicial no sustituye esas actas ni prueba que una tarea siga pendiente.

La traducción de la documentación y la firma de commits no acreditan
la implementación ni la validación experimental de A1–A10.

## English

F1-bootstrap.json preserves the result observed when the local structure
and Python environment were created. Its fields and codes are structured data.

PENDING, NOT_TESTED and NOT_RUN describe the status recorded at that time.
They are not a query of the current status.

docs/pendientes.md preserves the baseline's initial task list.
Task completion will be evidenced by subsequent records linked to commits.
The initial list neither replaces those records nor proves that a task
remains pending.

Documentation translation and commit signing do not establish implementation
or experimental validation of A1–A10.
