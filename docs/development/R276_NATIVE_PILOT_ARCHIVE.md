# R276 — Archivo analítico nativo del piloto

Construye dos instantáneas de revisión mediante AnalyticalProjection,
AnalyticalArchive y el resolutor de referencias nativo.

Preserva la caracterización candidata, identidad de instancia,
magnitudes exactas, evidencias disponibles, contadores, objetivos,
historia, ventanas y controles pendientes.

La línea base no cerrada y la evidencia no acreditada se representan
mediante ND explícito. No se sustituyen por cero.

Las instantáneas de revisión no son generaciones operacionales A9.
No conceden autoridad física ni admisión experimental.
