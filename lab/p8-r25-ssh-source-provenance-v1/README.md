# P8-R25 — Captura de fuentes SSH del runner (sin ejecución)

**Resultado material nuevo:** medir bytes y SHA-256 de `/etc/ssh/ssh_config` y de los archivos regulares `*.conf` listados directamente bajo `/etc/ssh/ssh_config.d` en la **imagen QCOW2 R9 congelada**, sin leer una VM activa. Los fragmentos se asocian a ocho perfiles SSH *solo como fuentes candidatas*, no como configuración efectiva. Este incremento no pretende cerrar las 261 barreras de R24 ni vincular los 348 campos de P8.

El colector privado autentica el recibo R24 (SHA-256 y estado de denegación), verifica el archivo de imagen original por su SHA-256, modo 0444, tamaño, ausencia de backing file y formato QCOW2, y usa exclusivamente `guestfish --ro --format=qcow2 -a <imagen> -i` con operaciones `is-symlink`, `ls` y `download`. **No usa `-d`, `--rw`, shell, libvirt de VM activa ni cliente invitado**. Calcula las huellas leyendo bytes en memoria, vuelve a comprobar el SHA de la imagen después, y escribe únicamente un recibo privado JSON 0600 dentro de carpeta 0700 (creación exclusiva, nunca sobrescribe). No guarda los contenidos ni imprime valores de configuración, rutas de IdentityFile, credenciales ni hosts.

La lógica pública solo analiza fixtures sintéticos. Las cuentas de directivas `Include`, `Host`, `Match` son **léxicas**. En ningún caso se afirma una resolución completa de `Include`, precedencia, expansión, entorno, `Match`, `ssh -G`, configuración efectiva, compatibilidad real de cliente, autorización o despacho. Cualquier enlace fuera de una excepción literal bloquea la captura. La única excepción es `20-systemd-ssh-proxy.conf` → `/usr/lib/systemd/ssh_config.d/20-systemd-ssh-proxy.conf`, observada en el diagnóstico privado del operador. Se verifica el destino exacto con `readlink`, los directorios padre sin enlaces, y la naturaleza regular no enlazada del archivo destino antes de leer sus bytes mediante ruta absoluta; no se siguen cadenas arbitrarias. El recibo registra la correspondencia literal y el hash medido sin almacenar contenidos. El reconocimiento de ese enlace no equivale a configuración efectiva. El directorio se limita a una sola capa, no se exploran rutas arbitrarias.

Antes de activar la adquisición, comprobar con el operador que la imagen fija es la base de desarrollo y no una unidad experimental sellada. Si el contenido ha cambiado, fallar cerrado y realizar nueva revisión de procedencia; no reemplazar el hash constante para forzar éxito.

El laboratorio de CI ejecuta `verify_p8_r25_ssh_source_provenance.py` y tests sintéticos: no necesita `guestfish`, QEMU, credenciales, recibos privados ni acceso a QCOW2. El script de adquisición **se ejecuta únicamente por acción explícita del operador** tras la instalación en worktree aislado. R25 no incluye commit, push, PR ni merge en la fase de staging.

El siguiente trabajo material será resolver de manera segura el árbol de `Include`, la precedencia real y la dependencia del usuario/entorno en una instancia aislada y aprobada, manteniendo la distinción entre las fuentes observadas y la configuración efectiva. P8, AL-06/07 abiertos, P9/A1–A10 sin iniciar.
